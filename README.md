# ProcureIQ

An AI-assisted enterprise procurement platform built with Java, Spring Boot, React, and PostgreSQL.

## Objective

Build a procurement system that simulates the Procure-to-Pay (P2P) lifecycle while exploring backend development, database management, AI integration, and software engineering fundamentals.

## Planned Features

- Purchase requisitions and approval workflows
- Purchase order management
- Goods receipt and invoice matching
- AI-assisted invoice discrepancy analysis
- Mock ERP integration and failure handling

## Tech Stack

- **Backend:** Java, Spring Boot
- **Frontend:** React
- **Database:** PostgreSQL
- **AI:** Gemini API (planned)

## Project Status

🚧 In development — currently in the initial setup and planning phase.

## Goal

Build a functional, tested, and deployable application while learning and applying real-world software engineering concepts.
